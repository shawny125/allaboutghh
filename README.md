# ALL ABOUT : 공항고 — 시간표 (1단계)

> 공항고의 오늘을 한눈에

컴시간에서 시간표를 실시간으로 가져와 보여주는 웹앱입니다.
학급 시간표, 교사별 시간표, 현재 교시 카운트다운, "이 선생님 지금 수업 중" 표시가 들어 있습니다.

## 0. 학교 원본 파일에서 데이터 만들기

기초시간표·강의실 배치표(HWP)와 명렬표(XLSX)를 읽어 앱이 쓰는 JSON 을 만듭니다.
**학기가 바뀌면 새 파일로 다시 돌리면 됩니다.**

```bash
python3 tools/hwp/build_data.py \
  --기초시간표 "1. 2학기 기초시간표 파일학급별.hwp" \
  --실제강의실 "2. ... 실제강의실.hwp" \
  --컴시간강의실 "3. ... 컴시간 상 강의실 배치.hwp" \
  --명렬표 "교사명렬표.xlsx"
```

만들어지는 파일

| 파일 | 내용 |
|---|---|
| `data/base-timetable.json` | 24개 학급 주간 시간표 + 이동수업 블록 |
| `data/electives.json` | 선택과목 블록 배치 + **실제 강의실** |
| `data/teacher-map.json` | 컴시간 마스킹 이름 → 실명 |
| `data/교사명렬표.csv` | 교직원 49명 + 담당 과목 |
| `data/검증리포트.md` | 원본 파일끼리 어긋난 부분 |

원본 파일의 오류나 표기 차이는 `data/corrections.json` 에 적어 두면 자동으로 바로잡힙니다.
파일을 고치지 않고 바로잡기 때문에, 다음 학기에 새 파일로 다시 돌려도 같은 보정이 그대로 적용됩니다.

현재 들어 있는 보정
- 3학년 3반 금요일 5교시: 기초시간표의 `D` → `A` (원본 오타)
- `중국어회화` → `중국어회화Ⅰ` 표기 통일
- 수요일 5·6교시 전 학급 `창체` 추가 (컴시간에는 비어 있음)

파이썬 표준 라이브러리와 `openpyxl` 만 있으면 됩니다. HWP 는 자체 파서(`tools/hwp/`)로 읽습니다.

## 0-1. 이동수업 강의실 — 반드시 실제 강의실로

**컴시간에 찍힌 강의실과 실제 수업하는 강의실이 다릅니다.**
2026학년도 2학기 기준 85개 선택강좌 중 **75개**가 다릅니다.

학생은 실제 강의실로 가야 하므로, 이 앱은 **항상 실제 강의실만** 표시합니다.
컴시간 값은 `컴시간강의실` 필드에 참고용으로만 담아 둡니다.

2·3학년 학생이 시간표 화면에서 자기 선택과목(A~E)을 한 번 고르면,
이동수업 칸에 **과목명과 실제 강의실**이 표시됩니다. 선택은 그 기기에만 저장됩니다.

> 학생 개인별 선택과목 배정 파일은 앱에 넣지 않았습니다.
> 학생 이름과 선택 내역이 웹에 올라가는 구조가 되기 때문입니다.
> 각자 자기 것만 고르는 방식이 같은 결과를 주면서 훨씬 안전합니다.

## 1. 왜 이런 구조인가

브라우저에서 컴시간을 직접 부를 수 없습니다(CORS 차단 + HTTP/HTTPS 혼용 차단).
그래서 중간에 서버를 하나 두고, 그 서버가 브라우저 대신 컴시간에 다녀옵니다.

```
학생·교사 휴대폰  →  우리 서버(/api)  →  컴시간
                        └ 20분 캐싱, 실패 시 마지막 성공 데이터 유지
```

**교사 시간표는 컴시간교사.kr 를 따로 긁지 않습니다.**
학급 시간표의 모든 칸에 담당 교사가 들어 있어서, 그것을 교사 기준으로 뒤집으면 같은 결과가 나옵니다.
출처가 하나라 두 화면이 어긋날 일이 없습니다.

**컴시간이 안 되면 학교 기초시간표로 넘어갑니다.**
컴시간 접속 실패 → 마지막 성공 데이터 → 기초시간표 순으로 내려갑니다.
어느 경우에도 빈 화면이 뜨지 않고, 화면 위에 어떤 자료를 보고 있는지 표시됩니다.

## 2. 배포 (Vercel, 무료)

### 준비물
- GitHub 계정
- Vercel 계정 (GitHub 로 가입하면 됩니다)

### 순서

1. 이 폴더를 GitHub 저장소에 올립니다. **저장소는 비공개(Private)로 만드세요.**

2. [vercel.com](https://vercel.com) → **Add New → Project** → 방금 만든 저장소 선택 → **Deploy**
   - 설정은 건드릴 것이 없습니다. `vercel.json` 이 알아서 처리합니다.

3. 배포가 끝나면 주소가 나옵니다. **가장 먼저 `/api/school` 을 열어 보세요.**

```
https://내주소.vercel.app/api/school
```

여기서 인천공항고가 검색되고 코드가 `67338` 로 나오면 연결 성공입니다.

### 검색이 안 되거나 코드가 다르면

`data/config.json` 을 고칩니다.

```json
{
  "schoolName": "인천공항고",       ← 검색이 안 되면 "인천공항고등학교" 로
  "schoolCodeHint": 67338          ← /api/school 에 나온 코드로
}
```

고치고 GitHub 에 올리면 Vercel 이 자동으로 다시 배포합니다.

### 로컬에서 먼저 보고 싶다면

```bash
npm install
npm run dev        # http://localhost:3000
```

## 3. 교사 실명 표시

컴시간은 교사 이름을 `이서*` 처럼 가려서 줍니다.
매핑표를 한 번 만들어 두면 그 다음부터는 실명으로 나옵니다. **학기 중에는 다시 만들 필요가 없습니다.**

### 이미 만들어져 있습니다

`build_data.py` 가 기초시간표에서 담당 과목을 읽어 `data/teacher-map.json` 을 채웁니다.
아래 도구는 기초시간표가 없을 때 명부 CSV 만으로 맞추는 예비 수단입니다.

### 2) 자동 대조

```bash
node tools/build-teacher-map.mjs data/교사명렬표.csv
```

- 이름 패턴(`이서*` → 성 '이', 둘째 글자 '서')과 과목을 함께 봐서 **대부분 자동으로 확정**됩니다.
- 확정된 결과는 `data/teacher-map.json` 에 저장됩니다.
- 애매한 건은 `data/teacher-map.review.csv` 로 빠집니다.

### 3) 애매한 건만 손으로

`data/teacher-map.review.csv` 의 **확정이름** 칸을 채우고

```bash
node tools/build-teacher-map.mjs --merge-review
```

### 같은 마스킹 이름에 두 분이 걸리는 경우

이 도구는 **같은 시간에 두 곳에서 수업하는 이름**을 찾아냅니다.
한 사람이 동시에 두 반에 있을 수는 없으니, 이건 두 분이 `이서*` 로 묶였다는 확실한 증거입니다.
이때는 과목별로 한 줄씩 검토 파일에 나오므로 각각 다른 이름을 적어 주면 됩니다.

```json
"이서*|통합사회": "이서연",
"이서*|문학": "이서준"
```

### 표시를 원치 않는 교사

값을 `null` 로 두면 실명 대신 마스킹 상태로 남습니다.

```json
"김민*": null
```

## 2-1. 교사 실명 매핑 (이미 끝났습니다)

기초시간표에 담당 교사가 실명으로 들어 있어서, 명렬표와 대조해 매핑이 자동으로 만들어졌습니다.
마스킹하면 겹치는 세 쌍도 담당 과목으로 갈렸습니다.

| 마스킹 | 겹치는 분 | 구분 방법 |
|---|---|---|
| 이승* | 이승연 · 이승언 | 이승연은 배정 수업이 없어 이승언으로 확정 |
| 박현* | 박현우(진로) · 박현선(스생·체육A) | 과목으로 구분 |
| 송지* | 송지현(영어B·진로) · 송지호(음연·음악) | 과목으로 구분 |

## 3-0. 색과 글씨 크기

- 메인 색 `#54A8F2`, 배경은 흰색과 옅은 물빛(`#F5FAFF` / `#E8F3FE`)
- 메인 색 위 글자는 `#0B2F4A`, 흰 배경 위 파란 글자는 `#14588F` (둘 다 WCAG AA 충족)
- 제목 `ALL ABOUT : 공항고` 는 29px, 강원교육튼튼체에 얇은 획을 덧대 조금 더 굵게 보이도록 했습니다

## 3-1. 글씨체

제목은 **강원교육튼튼체**, 본문은 **강원교육모두체**(Light 300 / Bold 700)를 씁니다.
보내주신 TTF 를 한글 11,172자 전체가 담긴 WOFF 로 추려 `public/fonts/` 에 넣었습니다.

- 세 파일 합쳐 약 2 MB — CDN 없이 프로젝트 안에서 바로 불러옵니다
- 인터넷이 느리거나 CDN 이 막혀도 글씨체가 깨지지 않습니다
- 원본 TTF(16 MB)를 그대로 쓰지 않은 이유는 첫 화면이 그만큼 늦게 뜨기 때문입니다

교체하려면 `public/fonts/` 의 파일과 `public/style.css` 맨 위 `@font-face` 만 바꾸면 됩니다.

## 3-1-1. 급식 (나이스 연동)

나이스 교육정보 개방 포털에서 그날 급식을 가져와 '내 반 오늘 수업' 아래에 보여줍니다.

- **학교 코드는 자동으로 찾습니다.** `data/config.json` 의 `neis.학교명` 으로 조회해서 기억합니다.
- 알레르기 번호는 메뉴 이름에서 떼어내 작은 글씨로 붙이고, 그날 쓰인 번호만 아래에 풀어 씁니다.
- 3시간 캐싱합니다. 급식은 하루에 한 번 바뀌니 충분합니다.
- **급식을 못 가져와도 앱의 나머지는 그대로 돕니다.** 급식 칸에만 사유가 표시됩니다.

### 인증키

인증키 없이도 동작하지만 요청 수 제한이 있습니다.
[open.neis.go.kr](https://open.neis.go.kr) 에서 무료로 발급받아 넣어 주세요.

**Vercel 환경변수 `NEIS_KEY` 에 넣는 쪽을 권합니다.** 저장소에 키가 남지 않습니다.

```
Vercel 프로젝트 → Settings → Environment Variables
  NEIS_KEY = 발급받은 키
```

`data/config.json` 의 `neis.인증키` 에 직접 적어도 되지만, 그러면 깃 저장소에 키가 들어갑니다.

## 3-2. 바로가기

`data/links.json` 만 고치면 화면에 바로 반영됩니다. 코드는 건드릴 필요 없습니다.
한 줄에 하나씩, 위에서부터 순서대로 표시됩니다.

| 종류 | 동작 | 필요한 값 |
|---|---|---|
| `link` | 새 창으로 주소 열기 | `url` |
| `copy` | 누르면 클립보드에 복사 | `value` |
| `page` | 앱 안의 다른 화면으로 이동 | `url` |

현재 들어 있는 항목

1. 학교 홈페이지 — https://gonghang-h.icehs.kr
2. Wi-Fi 비밀번호 — 누르면 복사 (`Sc_2021_pass`)
3. 리로스쿨 — https://gonghangh.riroschool.kr/
4. 교실 · 선생님 자리 안내도 — `public/map.html` 로 이동

**안내도 화면**은 `public/map.html` 에 준비 중 안내만 넣어 뒀습니다.
3D 모델이 완성되면 이 파일 내용을 바꾸면 됩니다. 주소(`/map.html`)와 바로가기는 그대로 두면 되고요.

> 복사 기능은 HTTPS 에서만 브라우저 기본 API 를 씁니다.
> HTTP 로 열었을 때를 대비해 예전 방식으로도 한 번 더 시도하고,
> 그래도 안 되면 "길게 눌러 직접 복사" 안내를 띄웁니다.

## 4. 공개 전에 확인할 것

지금은 **주소를 아는 사람이면 누구나** 볼 수 있는 상태입니다. 테스트 단계라 그렇게 해 뒀습니다.

학생들에게 열기 전에 정리하시면 좋을 것:

- **접근 제한** — 교내 구성원만 쓰게 할지. 간단한 코드 입력이나 로그인
- **교사 동의** — 실명과 현재 수업 위치를 함께 보여주는 화면입니다. 교무부·정보부에 미리 알리세요
- **CORS** — `api/_http.js` 의 `Access-Control-Allow-Origin` 을 `'*'` 에서 실제 도메인으로 바꾸기

## 5. 이게 깨질 수 있는 지점

컴시간은 공식 API 가 아닙니다. 컴시간 쪽이 내부 구조를 바꾸면 파싱이 멈춥니다.

그래서 이렇게 설계했습니다.

- **빈 화면이 뜨지 않습니다.** 조회에 실패하면 마지막으로 성공한 시간표를 보여주고, 화면 위에 "최신 시간표를 받지 못했다"는 안내가 뜹니다.
- `/api/school` 이 연결 상태 점검용입니다. 이상하면 여기부터 보세요.

**권장**: 하이컴시스템(컴시간 개발사)에 학교 명의로 정식 연동 방법을 문의해 두세요.
학교가 계약 주체이니 물어볼 자격이 있고, 공식 방법이 있으면 이 위험이 통째로 사라집니다.
